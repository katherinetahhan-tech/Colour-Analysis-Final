# Colour-Analysis

## Overview
This project determines the users' colour palette based on their features such as skins undertone, eye colour, hair colour and skin tone

## Requirements
- PyCharm (https://www.jetbrains.com/pycharm/download/?section=windows); download program for MacOS or Windows based on what you are using
- Python [version 3.14]
- Pillow (external library, used for displaying images)

## How to open the project in PyCharm
1. Download the Colour Analysis file to your downloads
3. Open PyCharm and click File > Open
4. Select "Colour Analysis Final" and press Open
5. Make sure that there is 4 JPG files for the colour analysis resuts for each season

## Installing Pillow
1. Go to https://pypi.org/project/pillow/#files
2. Download [version 13.0.0] to your downloads
3. Open the terminal tab at the bottom of PyCharm
4. Make sure the prompt starts with (.venv); if it doesn't, press the + in the temrinal and check again
6. Type: 'pip install pillow' 
7. Press Enter and let the library install

## How to run the program
1. Right click anywhere on the code and click on run or press the green play button at the top of the screen
2. The program will run at the bottom of the screen
3. Make sure that you are typing in the run window and not typing into the code before you begin
4. Type your answers into the run window when prompted and then press enter

## Notes
Answers can be written in lowercase or uppercase
